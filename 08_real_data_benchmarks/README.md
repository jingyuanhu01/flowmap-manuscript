# Real Data Benchmarks

This section is organized by benchmark type.

- `01_four_real_datasets`: benchmarks on cell cycle, pancreas, dentate gyrus, and LARRY data.
- `02_velocity_estimation_methods`: benchmarks comparing velocity-estimation inputs.

The notebooks read shared input data directly from the root `data/flowmap_manuscript` folder and write benchmark outputs to local `figures` or `intermediate_data` folders. Shared FlowMap helpers are imported from the root `flowmap_legacy` package.
