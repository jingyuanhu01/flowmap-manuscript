# Real Data Benchmarks

This section is organized by benchmark type.

- `01_four_real_datasets`: benchmarks on cell cycle, pancreas, dentate gyrus, and LARRY data.
- `02_velocity_estimation_methods`: benchmarks comparing velocity-estimation inputs.

The notebooks expect local `data`, `figures`, and, where needed, `scripts` paths in each benchmark folder. `data` and `scripts` are symlinks back to the shared repository locations.
